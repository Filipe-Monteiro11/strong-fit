# Strong Fit 💪

Site institucional de uma academia fictícia, feito com HTML e CSS.

## Tecnologias
- HTML5
- CSS3 (flexbox, Google Fonts, hover, box model)

## Funcionalidades
- Menu de navegação com âncoras
- Seções de Sobre, Atividades, Planos, Horários, Depoimentos e Contato
- Botão com efeito hover
- Tema escuro com laranja

## Como visualizar
Abra o arquivo `index.html` no navegador.
